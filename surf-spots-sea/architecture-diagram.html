🔌 外部APIサービス
OpenWeatherMap
リアルタイム天候データ: 気温、風速、風向、湿度、気圧
REST API (有料プラン)
Open-Meteo Marine
海洋気象データ: 波高、波向、波周期、うねり情報
REST API (無料)
Pexels
高品質な写真: サーフスポット、ゴルフコースの画像
REST API (無料)
OpenStreetMap
地図タイル画像: 世界中の地図データ
Tile Server (無料)

📊 データフロー

1
アプリ起動
ユーザーがブラウザでアクセス → Vue.js アプリ初期化 → locations.js からスポットデータ読み込み
2
地図表示
Leaflet.js で地図初期化 → OpenStreetMap タイル取得 → 各スポットにマーカー配置（グレー）
3
天候データ取得（並列）
全スポットの天候データを並列取得 → OpenWeatherMap + Open-Meteo Marine API → データ受信後マーカーの色を更新
4
写真取得（バックグラウンド）
Pexels API で写真検索 → 5件ずつ並列取得 → リストビューとツールチップに表示
5
ユーザー操作
マーカークリック → ツールチップ表示 → 詳細ポップアップ → リアルタイムデータ表示
6
自動更新
30分ごとに天候データを自動更新 → マーカーの色とツールチップを更新
