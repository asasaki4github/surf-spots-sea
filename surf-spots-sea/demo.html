デモ版について

⚠️ これはデモ版です

このHTMLファイルは、Node.jsがインストールされていない環境でもアプリの動作を確認できるデモ版です。 実際の波情報はモックデータ（ダミーデータ）を使用しています。

対象スポット

  • • Nongsa Beach (バタム島)
  • • Trikora Beach (ビンタン島)
  • • Desaru Beach (ジョホール)
  • • Tioman Island (ティオマン島)
  • • Parai Beach (バンカ島)

完全版の実行方法

実際の波情報を取得するには、Node.jsをインストールして以下を実行してください： 

cd surf-spots-sea
npm install
npm run dev
